# AutoExplore Extended

An Elin mod that teaches [Yuof's AutoExplore](https://steamcommunity.com/sharedfiles/filedetails/?id=3365829584) to use more tools, and adds a settings window for all of it. Requires AutoExplore.

## Tools
- **Crowbar or lockpick:** opens locked chests you may legally open. Practice chests are picked by hand: no damage, no charges used.
- **Shears:** shears every shearable animal.
- **Shovel:** digs up floors and tracks, in Gather or Mining mode.
- **Optional:** dig tracks while mining, swapping to your best shovel and back.

## Settings window
System > Mod > AutoExplore Extended, or middle-click yourself. Every AutoExplore setting in one place, saved to AutoExplore's own config; changes apply immediately. Hover a setting to see what it does.

## Filters
- Named restriction lists for gathering, mining and pickup.
- Material filters per tool (pickaxe, axe, shovel): blacklist or whitelist.
- A checklist editor beside the raw list.

## Also
- Works with Instant Actions (prying and picking keep their normal length).
- Includes the [Auto-Explore Shearing Extension](https://steamcommunity.com/sharedfiles/filedetails/?id=3837309390); its own shearing turns off while that mod is enabled.

English, Japanese and Simplified Chinese. Translations: Claude (AI).
